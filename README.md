# DeLiora Essence by Patidar

A luxury fragrance house web application built with **HTML5, CSS3, Bootstrap 5, and vanilla JavaScript**.

## Zero Dependencies / Standalone
This project requires **no `node_modules`**, no `npm install`, and no build commands. All assets and scripts run natively in the browser.

## How to Run Locally

### Option 1: Python Built-In Web Server (Recommended)
On macOS/Linux, Python 3 is pre-installed:
```bash
python3 -m http.server 8080
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

### Option 2: VS Code / IDE Live Server
Right-click on `index.html` and select **"Open with Live Server"**.

### Option 3: Static Hosting (GitHub Pages, Netlify, Vercel, cPanel, Apache, Nginx)
Directly deploy or upload the project root directory. No build step or Node.js environment is required.
